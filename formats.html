3D format guide

Same model, different packaging. Each format keeps a different subset of the model — geometry, textures, rig, animation — so the right choice depends on where the file is going.

GLB

recommended
Textures ✓Animation ✓Rig ✓

The all-in-one modern format (binary glTF). Geometry, PBR textures, materials, rigging, and animation are embedded in a single file — nothing travels separately, so nothing gets lost.

Best for: web, games, and this app — the viewer, thumbnails, and the Three.js converter all speak GLB natively.

FBX

Textures ✓Animation ✓Rig ✓

Autodesk's professional format from the film and 3ds Max / Maya world. Its strength is carrying rigs and multiple animation clips in one file. Proprietary and a little bloated, but universally accepted by pro tools.

Best for: Mixamo (it speaks FBX), Unity, Unreal, and DCC tools like Maya or Blender.

OBJ

Textures ~ separate filesAnimation ✗Rig ✗

The 30-year-old universal format: geometry as plain text. Materials and textures live in separate loose files (a .mtl plus images) that are easy to lose — which is why OBJs so often show up untextured. No animation, no rig, ever.

Best for: a simple static mesh that has to open everywhere, including old software.

STL

Textures ✗Animation ✗Rig ✗

The 3D-printing format. Bare triangle soup: no color, no textures, no units, no animation. It looks like nothing on screen because it was never meant to be looked at — it describes a shape to a printer.

Best for: 3D printing, and only that.

USDZ

Textures ✓Animation ✓Rig ~ limited

Apple and Pixar's format for augmented reality. Its party trick is iOS Quick Look: tap the file on an iPhone and the model appears in the room at real scale. Part of the broader USD scene format used in film.

Best for: showing a model in AR on Apple devices.

MP4

not a model

Not a 3D file at all — a rendered turntable video of the model. Nobody can open it in a 3D tool, rotate it, or use it in a project.

Best for: sharing and showcase posts.

GIF

not a model

The same idea as MP4 but shorter, loopier, and lower quality: a small looping clip of the model.

Best for: Discord, chat, and README embeds.

Picking a download?

GLB for your own projects, FBX when it's headed to Mixamo, STL to print, MP4 / GIF just to show somebody.
