MeshCoder automatic setup

Native Windows setup — no WSL2, no conda. This creates a Python 3.10 env in Documents\Hunyuan3D\MeshCoderEnv, installs MeshCoder's packages into it (several GB), and downloads the checkpoints (~6.6 GB) from Hugging Face. Expect 20-40 minutes, mostly downloading. You can cancel and re-run; finished steps are kept.

The checkpoints sit behind a one-time access form on the model page (name, email, affiliation, license checkbox — auto-approved). Submit it once, then paste a Hugging Face token below. The token is used only for this download and is not saved.
