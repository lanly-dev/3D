Prepare Blender for MeshCoder scripts

Generated scripts start with from bpy_lib import *, and bpy_lib needs torch — which Blender's own Python doesn't ship, so the script dies with ModuleNotFoundError: No module named 'torch'.

This finds your Blender install and adds CPU-only torch (~200 MB) to Blender's per-user modules folder (%APPDATA%\Blender Foundation\Blender\<version>\scripts\modules). The Blender install itself is not touched and no admin rights are needed. Afterwards it verifies by launching Blender headless and importing bpy_lib for real. Safe to re-run — an install that's already prepared is just verified.
