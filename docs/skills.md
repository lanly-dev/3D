# Skills

Reusable procedures that have been verified to work in this project. Each skill
is an entry with: what it does, when to use it, the steps, and how to verify it
succeeded.

## Adding a skill

Append a new entry:

```markdown
## <skill name>

**What:** One sentence.

**When:** Trigger conditions.

**Steps:**
1. ...
2. ...

**Verify:** How to confirm it worked.
```

A skill that can't be verified is a guess, not a skill.
